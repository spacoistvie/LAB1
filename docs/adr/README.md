# Реестр архитектурных решений (ADRs)

Формат: **MADR** (Markdown Any Decision Records). Статусы: `accepted` — принято,
`proposed` — на обсуждении, `rejected` — отклонено, `superseded` — заменено
более поздним ADR.

## Обозначения последствий

* `+` — положительные последствия;
* `−` — отрицательные риски/издержки;
* `○` — нейтральные последствия.
